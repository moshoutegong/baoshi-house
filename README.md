# 宝石小屋

一款为纪念一只小鹦鹉而做的学习养宠游戏。孩子在 iPad 上答题、喂养、装扮一只叫"宝石"的鹦鹉，再带它去闯解谜关卡。

## 缘起

孩子换牙的时候，对牙仙子许了一个愿望：想要一只鹦鹉。

妈妈悄悄买回了一只。孩子一见到它就喜欢得不得了，给它取名叫"宝石"。

<p align="center">
  <img src="docs/baoshi-shoulder.webp" alt="宝石站在孩子的肩头" width="420">
</p>

可是没过几天，宝石不小心掉进了飘窗上的鱼缸里，没能救回来。

孩子非常伤心，亲手埋葬了宝石，又在一块石头上写下：

> 短暂相遇，永远想念我的宝石
> 2026 年 11 月 8 日

<p align="center">
  <img src="docs/baoshi-stone.jpg" alt="孩子在石头上写下对宝石的想念" width="520">
</p>

为了纪念宝石，也为了让孩子的心里好受一些，我们借助 Claude Fable 5.2 做了这个"宝石小屋"。在这里，宝石还在：孩子可以每天喂它、陪它玩铃铛、给它换羽毛戴帽子，带它去很远的地方探险。

当然，不能只让孩子玩。鸟粮、金币和探险票都不是白来的，要靠答题去赚。照顾宝石的每一步，都从认真学习开始。

## 玩法

- **答题**：数学、语文、英语、科学四科，共 400 多道题，每轮 5 题，答完立刻看解析。答对得鸟粮，答对 3 题得探险票，答对 4 题得铃铛，全对再得提示羽毛。
- **养宠**：饱腹度按真实时间下降，从"有点饿"到"昏迷不醒"共六个阶段，每个阶段宝石的样子都不同。饿到昏迷要答题抢救。
- **闯关**：回合制棋盘解谜，共 4 个世界 40 关。要拿齐 3 颗宝石，鸟巢才会打开。可以无限撤销，按步数评一到三星。
- **装扮**：升级解锁羽毛颜色，用金币买帽子、眼镜、围巾和不同风格的小屋。

### 闯关里的机关

| 机关 | 作用 |
|---|---|
| 木箱 | 只能推不能拉；推进缺口会填平成桥 |
| 裂砖 | 踩过一次就塌 |
| 压力板和闸门 | 木箱压住压力板，闸门才打开 |
| 传送漩涡 | 走进一个，从同色的另一个出来 |
| 冰面 | 踩上去一直滑到头，木箱也会滑 |

每一关都由程序穷举验证过有解，并算出了最少步数。

## 在电脑上试玩

游戏是纯静态网页，用任意静态服务器打开 `index.html` 即可。Windows 上可以直接运行自带的脚本：

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

然后在浏览器里打开 `http://localhost:8780/`。

## 编译和安装

每次往 `main` 分支提交，GitHub Actions 会在云端 Mac 上自动编译，产出未签名的 `BaoshiHouse-unsigned.ipa`，在 Actions 运行记录页面底部的 Artifacts 里下载。

IPA 没有签名，需要自己用 Apple ID 签名后才能安装，步骤见 [安装说明.md](安装说明.md)。

- App 标识符：`com.baoshi.house`
- 最低系统：iOS / iPadOS 15.0
